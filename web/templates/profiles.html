Profile YAML Guide

Each profile is a YAML blob with these top-level keys:

  • search — title keywords, tech stack, JSearch queries
  • scoring — weights, core tech, experience targets
  • location — India-friendly / timezone filters
  • outreach — candidate name, LinkedIn search titles, DM templates

Create or edit a profile and paste valid YAML in the config box.
